# 🤖 ربات قیمت‌دهی روزانه بازار

ربات تلگرامی حرفه‌ای برای ارسال خودکار قیمت طلا، تتر، صندوق‌های سرمایه‌گذاری و سایر نمادهای مالی به کانال تلگرام.

---

## ✨ قابلیت‌های کلیدی

- 📊 **مدیریت چند نماد** - افزودن، ویرایش و حذف نمادها از داشبورد وب
- ⏰ **زمان‌بندی داینامیک** - تنظیم ساعات دلخواه ارسال از طریق پنل
- 📝 **قالب کپشن قابل ویرایش** - تغییر متن پست بدون دستکاری کد
- 🖼 **مدیریت تصویر پست** - تغییر لینک تصویر از داشبورد
- 📱 **داشبورد وب حرفه‌ای** - پنل مدیریت کامل با احراز هویت امن
- 🚨 **سیستم هشدار هوشمند** - ارسال خودکار خطاها به پی‌وی مدیر
- 🔄 **معماری خودترمیم** - سوئیچ خودکار به منبع پشتیبان در صورت خرابی
- 💾 **ذخیره‌سازی داینامیک** - استفاده از Cloudflare KV برای تنظیمات
- 💰 **۱۰۰٪ رایگان** - اجرا روی Free Tier کلادفلر

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- ✅ حساب [Cloudflare](https://dash.cloudflare.com) (پلن رایگان کافی است)
- ✅ حساب [GitHub](https://github.com)
- ✅ ربات تلگرام (ساخته شده با [@BotFather](https://t.me/BotFather))
- ✅ کانال تلگرام با دسترسی ادمین برای ربات

### مراحل نصب گام‌به‌گام

#### ۱. کلون کردن مخزن

    git clone https://github.com/YOUR_USERNAME/my-price-bazar.git
    cd my-price-bazar

#### ۲. ساخت فضای ذخیره‌سازی در کلادفلر

1. به داشبورد کلادفلر بروید
2. از منوی سمت چپ: **Workers & Pages** > **KV**
3. روی **Create a namespace** کلیک کنید
4. نام: `BOT_CONFIG`
5. آی‌دی تولید شده را کپی کنید

#### ۳. ویرایش فایل `wrangler.toml`

آی‌دی کپی شده را در بخش زیر قرار دهید:

    [[kv_namespaces]]
    binding = "BOT_CONFIG"
    id = "YOUR_KV_ID_HERE"

#### ۴. تنظیم متغیرهای محیطی در کلادفلر

در داشبورد کلادفلر > پروژه شما > **Settings** > **Variables**:

| متغیر | نوع | توضیحات |
|-------|------|---------|
| `BOT_TOKEN` | 🔒 Secret | توکن ربات تلگرام از BotFather |
| `ADMIN_PASSWORD` | 🔒 Secret | رمز عبور داشبورد (دلخواه) |
| `DEFAULT_CHANNEL_ID` | Variable | آیدی کانال هدف (مثال: `@PulseHub_co`) |
| `ADMIN_USER_ID` | Variable | آیدی عددی شما در تلگرام |
| `PHOTO_URL` | Variable | لینک پیش‌فرض تصویر پست |

#### ۵. اتصال به GitHub و Deploy

1. در داشبورد کلادفلر: **Workers & Pages** > **Create Application**
2. گزینه **Connect to Git** را انتخاب کنید
3. مخزن `my-price-bazar` را انتخاب کنید
4. روی **Save and Deploy** کلیک کنید

#### ۶. تنظیم Cron Job

1. به تب **Triggers** بروید
2. روی **Add Cron Trigger** کلیک کنید
3. مقدار زیر را وارد کنید:

    */10 * * * *

## 🛠️ افزودن نماد جدید

برای افزودن نماد جدید از طریق داشبورد:

1. وارد داشبورد شوید
2. به تب **📊 نمادها** بروید
3. روی **➕ افزودن نماد جدید** کلیک کنید
4. اطلاعات را پر کنید:
   - **شناسه یکتا**: نام انگلیسی کوتاه (مثل: `dollar`)
   - **نام نمایشی**: نام فارسی (مثل: `دلار آزاد`)
   - **ایموجی**: نماد نمایشی (مثل: 💵)
   - **نوع منبع**: `TGJU` / `نوبیتکس` / `ایموفید` / `سفارشی`
   - **آدرس/اسلاگ**: برای TGJU فقط اسلاگ، برای بقیه URL کامل
   - **لیبل جستجو**: متنی که قبل از قیمت می‌آید (مثل: `نرخ فعلی`)
   - **واحد منبع**: ریال یا تومان
   - **محدوده مجاز**: حداقل و حداکثر قیمت منطقی

## 📝 قالب کپشن

متغیرهای قابل استفاده در قالب کپشن:

| متغیر | توضیحات |
|--------|---------|
| `{date}` | تاریخ شمسی |
| `{time}` | ساعت ارسال |
| `{prices}` | لیست قیمت‌های فعال |
| `{channel}` | آیدی کانال |

**مثال:**

    📊 <b>قیمت‌های لحظه‌ای بازار</b>
    🗓 {date} | ساعت {time}
    
    {prices}
    
    #قیمت_طلا #تتر #سرمایه_گذاری
    
    🆔 {channel}
