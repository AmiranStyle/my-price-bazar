# 🤖 ربات قیمت‌دهی روزانه بازار

ربات تلگرامی برای ارسال خودکار قیمت طلا، تتر، صندوق‌های سرمایه‌گذاری و سایر نمادها به کانال تلگرام.

## ✨ قابلیت‌ها

- 📊 **مدیریت چند نماد**: افزودن/ویرایش/حذف نمادها از داشبورد
- ⏰ **زمان‌بندی داینامیک**: تنظیم ساعات ارسال از داشبورد
- 📝 **قالب کپشن**: ویرایش متن پست بدون دستکاری کد
- 🖼 **تغییر تصویر**: آپلود و تغییر لینک تصویر پست
- 📱 **داشبورد وب**: پنل مدیریت کامل با احراز هویت
- 🚨 **هشدار خطا**: ارسال خودکار خطاها به پی‌وی مدیر
- 🔄 **خودترمیمی**: منابع پشتیبان در صورت خرابی منبع اصلی

## 🏗 معماری پروژه
src/
├── index.js # نقطه ورود اصلی
├── config/ # تنظیمات پیش‌فرض
├── utils/ # ابزارهای عمومی
├── services/ # سرویس‌ها (KV, قیمت, تلگرام)
├── core/ # منطق اصلی (ساخت پست)
└── ui/ # رابط کاربری داشبورد
